## Yenilikler

- **Albümleri bulmak artık kolay**
  - Aramada **Albümler** bölümü: sanatçı ya da albüm adı yaz (ör. "daft punk discovery"), albüm kartına tıkla.
  - Sorgu bir albümü hedefliyorsa (sanatçı + albüm adı) albüm doğrudan açılır.
  - Şarkı ekranında **"Albümü aç"**: şarkının albümündeki tüm parçaları listeler.
  - Albüm ekranında: **Tümünü indir**, kutularla **Seçilenleri indir** ya da satırdaki düğmeyle tek parça.
- Sürümler artık GitHub Actions üzerinde derlenip SHA-256 özetleriyle yayımlanıyor.

**English:** Albums are now easy to find — search shows an **Albums** section, album searches open the
album directly, and every song has an **Open album** button. From the album view you can download all
tracks, a selection, or a single track. Builds are now produced on GitHub Actions with SHA-256
checksums. Binaries are not yet code-signed; see CODE_SIGNING.md.
